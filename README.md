# Portfolio Website

This folder contains a GitHub Pages-ready portfolio for Perinpanayagam Sivasankar.

## What is included

- Responsive single-page portfolio
- Hero, About, Skills, Projects, Education, Certifications, and Contact sections
- No build step required
- Ready to deploy on GitHub Pages from the `docs/` folder

## Deploy on GitHub Pages

1. Push this repository to GitHub.
2. Open the repository settings.
3. Go to `Pages`.
4. Set the source to `Deploy from a branch`.
5. Select branch `main` and folder `/docs`.
6. Save and wait for GitHub to publish the site.

## Update your details

Edit `index.html` and `script.js` if you want to change:

- About text
- Skills
- Projects
- Contact links
- Education and certifications

## Local preview

Open `docs/index.html` in a browser, or serve the `docs` folder with any static file server.
